# Changelog

## 0.2.3

- Added a target-free, single-roll button to the built-in Library Trader.
- Renamed the target-based action to Auto-roll.
- Prioritized exact and prefix enchantment matches, making Protection IV selectable before its variants.
- Added scrolling through all matching Library auto-roll suggestions.
- Protected pending payments and retained traded-villager locking during manual rerolls.

## 0.2.2

- Added an internal villager-only workstation, removing the adjacent-Trader requirement.
- Added automatic loading of an eligible archive villager and return on panel/screen close.
- Preserved workstation villagers in block saves and dropped block items.
- Displayed original and discounted prices together.

## 0.2.1

- Added real villager inventory slots and combined trading.
- Improved book search, aligned price-guide scrolling and JEI panel exclusion.

Earlier development builds were not public releases. The first public version should be labelled beta until its rendered UI and multiplayer behavior have been checked in a clean installation.
